# Thermal history

These are earlier development snapshots, preserved without content changes.
Their folder labels have been shortened for a clean archive listing. Original
paths and archived locations are recorded in MANIFEST.json. Restore a snapshot
to its original path before using its older absolute build configuration.
Historical firmware version strings and binary filenames remain unchanged
inside the archive to preserve traceability and verified rollback artifacts.
Do not flash a historical version merely to rename it.

Production release directories and CURRENT pointers were not moved.
